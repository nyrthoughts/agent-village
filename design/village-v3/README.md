# Agent Village design pack, v2 visuals

Step 2 of the brief, second visual iteration: design only, awaiting validation. Start with `DESIGN.md`. The v1 pack (rejected look) stays in `../village-v2/` for comparison.

- Boards: `visuals/01` to `visuals/06`.
- How v1 was audited and how the direction was chosen: `AUDIT.md`.
- Review of these boards before showing them: `REVIEW.md`.
- Scene generator and render jobs (Blender 5.2, Cycles): `blender/`.
- Rendered layers, frames and assets: `renders/`. Asset list with sizes and anchors: `asset-manifest.json`.
- Clickable composite of the layers: `prototype/app.html` (serve the folder over http, for example `node shoot.mjs` does it). Not production code.

All data is demo data. Names are fictional. No image-generation model and no paid call were used.
