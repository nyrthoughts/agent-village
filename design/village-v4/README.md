# Agent Village design pack, RPG village

Step 2 of the brief, third visual iteration: design only, awaiting validation. Start with `DESIGN.md`.

- Boards: `visuals/01` to `visuals/06`.
- Earlier iterations kept for comparison: `../village-v2/` (first pass) and `../village-v3/` (architectural model).
- Village generator and render jobs (Blender 5.2, Cycles, toon shading): `blender/`. Shared helpers live in `../village-v3/blender/av.py`.
- Rendered layers, frames and assets: `renders/`. Asset list with sizes and anchors: `asset-manifest.json`.
- Composite and chrome: `prototype/app.html` (serve over http; `node shoot.mjs` does it). Not production code.

All data is demo data. Names are fictional. Genre-level inspiration only: nothing is taken from an existing game. No image-generation model and no paid call were used.
